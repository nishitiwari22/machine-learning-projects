<h1>🎨 Hobby-to-Artist Predictor</h1>

<p>
A data-driven project that explores how personal hobbies can influence
creative potential and artistic career paths. The goal of this project
is to analyze patterns between hobbies and emerging artist categories,
and suggest possible artistic identities based on a person’s interests.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
Many successful artists began their journey through hobbies rather than
formal training. This project attempts to answer:
</p>

<ul>
  <li>How do hobbies shape personality and creativity?</li>
  <li>Can hobbies predict artistic inclinations?</li>
  <li>What type of artist could someone become based on their interests?</li>
</ul>

<p>
Using a dataset of hobbies and artist profiles, this project applies
machine learning techniques to identify patterns and generate predictions.
</p>

<hr>

<h2>🎯 Objectives</h2>
<ul>
  <li>Analyze the relationship between hobbies and creative professions.</li>
  <li>Build a predictive model to suggest artist types.</li>
  <li>Visualize personality–hobby–artist correlations.</li>
  <li>Create an interactive interface for users to input hobbies.</li>
</ul>

<hr>

<h2>🧠 Problem Statement</h2>
<p>
People often underestimate how their hobbies reflect their personality
and potential creative paths. This project aims to build a system that
maps hobbies to artistic domains such as:
</p>

<ul>
  <li>Visual Artist</li>
  <li>Musician</li>
  <li>Writer</li>
  <li>Dancer</li>
  <li>Digital Creator</li>
  <li>Photographer</li>
  <li>Designer</li>
</ul>

<hr>

<h2>📊 Dataset</h2>
<p>
The dataset contains:
</p>
<ul>
  <li>List of hobbies</li>
  <li>Personality traits (optional)</li>
  <li>Known artist categories</li>
</ul>

<p>
Data sources may include:
</p>
<ul>
  <li>Public artist interviews</li>
  <li>Survey-based datasets</li>
  <li>Self-created datasets</li>

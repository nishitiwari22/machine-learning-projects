🟡 Ensembles behave like regularization effects, but they don’t modify the loss function

“Regularization directly penalizes model complexity through the loss function, while ensemble methods like bagging and boosting reduce overfitting indirectly by averaging or sequentially correcting models. So ensembles act as an implicit form of regularization, even though they are not regularization techniques in the mathematical sense.”
